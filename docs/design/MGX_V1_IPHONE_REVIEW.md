# MGX Play比較：iPhone確認シート

#293の形成的な比較用。実際の対局・採点は行わない。A/B/Cは未採用案。

## 開く

MacとiPhoneを同じWi-Fiへ接続し、Safariで
`http://192.168.2.100:8794/play-comparison.html` を開く。
このURLは今回のMac上の一時配信。Macの停止・ネットワーク変更後は使えない。
再配信する場合は `docs/design/prototypes` のみを公開し、リポジトリ全体を配信しない。

所要時間は1案あたり約3分。実施日、端末名、OS、文字サイズ、縦横を記録する。
読みづらい場合も文字サイズを小さくして解決しない。

## 各案で同じ課題を行う

1. NLHを選び、画面を初めて見た時点で「誰の手番」「Pot」「Callに必要な額」を読み上げる。
   可能なら協力者が表示から回答までを計測する。
2. 基本Actionとサイズpresetを探して操作する。金額入力で「合計額」と「追加額」を説明する。
   不正な額で確定されず、正しい額で確定できることを確認する。
3. 履歴を1タップで開いて閉じる。現在の判断へすぐ戻れるか確認する。
4. Stud8へ切り替え、自分の札と相手の公開札を区別する。
5. 2-7TDへ切り替え、交換する札を選び、交換枚数を確認する。
6. 待機状態でCheckを予約し、手番の変化時に古い予約が残らないことを確認する。
7. 縦横を切り替え、Safariのアドレスバーが表示された状態でもActionが押せるか確認する。

片手の持ち方は普段どおり。誤タップ、押し直し、見切れ、札/Pot/Seatの重なり、
Safariの表示領域による下端の隠れを記録する。好みと操作の成否は分けて記録する。
