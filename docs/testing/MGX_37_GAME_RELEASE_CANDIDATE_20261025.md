別担当が公開候補のブラウザを初見で確認し、デスクトップのボード系で席が重なる、勝敗の手がかりがデスクトップに無くドロー中にモバイルから消える、日本語画面に英語の操作見出しが混じる、という3件を挙げた。候補ブランチで、ボード系の席幅・カード寸法とStud専用バッジの誤表示を修正した。再レビューで1024px幅の操作欄が画面外へ出る問題も見つかり、1200px未満では左の情報欄を畳んで操作欄を全表示するようにした。NLH、PLO、5-Card PLO、Dramahaを含む13種目×4画面幅（1024×768、1280×720、1440×900、1920×1080）で6席の重なりと横方向の見切れが無いことをブラウザで確認した。NLH・Razz・2-7のiPhone相当縦横画面では同じ対局骨格を確認し、デスクトップでも4種目の勝敗手がかりと日本語操作表示を確認した。PLO系の手札2枚・場3枚の条件を短い手がかりに加え、ベットの操作ボタンと金額ショートカットも日本語化した。既知不具合49件、RL安全性63件、関連UI57件、レイアウト・対局のブラウザ検査18件、ビルド、変更ファイルのlintは成功した。これらはブラウザと自動検査であり、物理端末の指操作や人の初見評価を実施したという意味ではない。
