## 検証の結果

- フロントの全体テスト：**415ファイル、2,560件成功、既存の1件スキップ**。スキップは汎用進行テストのOFC。OFCは別途ブラウザで1ハンド完走している。
- 最終の文言・導線調整後の対象テスト：**7ファイル、72件成功**。
- 対人サーバー：**49件成功**。通常/オールイン/分配、3種目×2〜6人、保存・再開、本人以外の手札を返さないこと、接続表示を確認。
- WebKit/Chromium × 日本語/English × 縦/横：**104画面**でページ例外・横はみ出しなし。表示中のセレクトはすべて44px以上。入力中の大会設定、保存・再読込、練習会の編集も確認。
- 登録なしの実プレイ：**26種目を各1ハンド**。24リング種目は交互に縦/横、Chineseは横、OFCは縦。すべての種目を両方向で完走したという意味ではない。
- 友人戦：Badugi 2席14操作、A-5 3席21操作、2-7 6席42操作で3回の交換と精算まで完了。途中再読み込みから復帰。WebSocketを無効にした既存のフォールバック試験も成功。
- FL Hold’em：PC 10ハンド、iPhone相当のChromium 10ハンド、WebKit 10ハンド。履歴・リプレイ・精算まで確認。
- 2-7 Single Draw：WebKit 10ハンド完走。追加のWebKit 10ハンドで明示的な金額指定2回、履歴10件、リプレイ、精算まで成功。詳細は [verification.json](verification.json)。
- 自由設定大会：1,500点・7分レベル・参加費0で実際に開始し、再開後の設定とレベル終了時刻が一致。
- ビルド成功。変更したソースの静的チェックはエラー・警告とも0件。追加した実行時依存の監査は脆弱性0件。既存の大きいファイル分割/循環分割の警告は残る。

## プレイ確認で発見し、修正した点

1. 2-7 Single Drawは名前だけでなく実装もNLへ変更。4回の固定レイズ上限を除き、最小レイズ・短いオールイン・再レイズ権・投資額別のサイドポットを追加した。
2. Archieはハイ9のペア以上、ロー8以下の異なる5ランクに修正。両方不成立なら通常のハイ比較で全体を分配する。[WSOPの規則](https://assets.wsopcdn.com/wsop/853ee602-e1e9-4019-a0cf-381419d805c6.pdf)、[BARGEの不成立時規則](https://www.barge.org/rulebook/archie.html)。ハイの最低ペアにはハウスルール差があるため、MGXの99以上を画面に明示。
3. ペアのある手を8-or-betterローとして成立させていた共通判定を修正。
4. BadeuceyのBadugi側でAを低く扱っていた点を修正。Aは高いカードで、5-4-3-2が最良。[BARGEのBadeucy規則](https://www.barge.org/rulebook.pdf)。通常BadugiとBadaceyのAは低いまま。
5. 全席練習の巻き戻しで、Badugiの旧状態が残る問題を修正。山札だけでなく制御状態も戻す。
6. 自由設定大会の開始前表示が、選択中の通常大会の人数/持ち点/参加費を示していた点を修正。開始に使う設定から表示する。
7. 休憩を早く終了してもレベル期限に元の休憩時間が残る点を修正。保存データも更新する。
8. 友人戦の接続状態が保存データの読み直しで消える点を修正。実際の接続情報を表示に反映し、プロセス再起動時に過去の接続を復活させない。
9. Safariの標準セレクトが高さ指定を無視して21〜23pxになる点を修正。44px以上と矢印を明示した。

## 今回の範囲と残る確認

- **iPhone実機の再検証は未完了**。ペアリング一覧にはiPhone 16があるが、USB Web Inspectorは「Device is not connected」で接続できず、USB機器一覧も空だった。今回のWebKit結果を実機結果として扱わない。Xcodeは起動していない。
- 友人戦の初期対象は上記3種目。37種目すべての対人化、友人卓での自動MIX切替、オンラインの複数卓大会はこの実装に含めない。
- 自由設定のアプリ内大会はBadugiのCPU練習大会。対人大会の自由ストラクチャーや賞金設定は提供しない。必ず何分で終了するという所要時間保証はしない。
- 役判定は完成した4/5枚の2手比較。Omahaのホールカード＋ボード入力やChineseの3段比較は未対応と画面に明示。
- 手札提案と反復練習は対応する3種目に絞る。ソルバーは追加していない。
- 練習会は予定・招待・手入力の結果を残す機能まで。一般向けの定期大会、ポイントシーズン、運営担当・参加需要の確認は未実施。
- 翻訳は主要導線を対象とし、既存の専門的な診断ログ・保存済み大会名・ユーザーが入力した名前まで自動翻訳するものではない。
- Razzduceyの現行Badugi側はAを低く扱う。今回修正したBadeuceyとは別に、MGXの現行ルールを説明カードで明示した。標準ルールとの差の再監査対象として残す。
