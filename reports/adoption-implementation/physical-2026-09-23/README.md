## 今回直した問題

1. **HTTPのローカル接続で練習開始・練習会保存が失敗する。** 保存用IDに `crypto.randomUUID()` を直接使っていた。HTTPSのネイティブUUIDは維持し、使えない環境では端末内記録用IDを生成する。練習条件、MIX受取、クイズ回答も同じ処理に統一した。認証やルーム秘密値には使用しない。
2. **Stud系にSB/BB/BTNなどの不要な位置を表示していた。** Stud/Razz系で位置ラベルを省く。NLHなどの位置表示は維持。カードの公開・非公開処理やゲーム進行は変更していない。
3. **友人戦で「ベット」と「ベット単位」が詰まり、操作の強調がCPU戦と違った。** 共通の見出し・手番表示・コール/チェック/レイズのスタイルに揃えた。修正後に2/3/6人卓をもう一度完了し、共通表示の検査も追加した。

対象テスト101件、既知の不具合47件、RL安全性56件、合計204件が成功。ビルドと変更ソースの静的チェックも成功。既存のビルド分割警告は残る。以前の全体2,560件は今回再実行した数に含めない。

## 方法と証拠
