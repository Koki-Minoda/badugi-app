# D03 Badugi Standard controller v2 adoption evidence

The frozen evaluation ran at code SHA `7fe453d8239d4206ad42e98a4baa855814d823ee` with ONNX SHA-256 `af31b433508c5e5a941ed04463380721e32fc7ebfe6715fa7b790396be91c80c`. The candidate and the published Beginner each played 8,000 independent real-controller sessions of 20 continuous hands, across ten seat/mode groups and four scripted opponent policies, using disjoint unused seeds. Hands within a session were not counted as independent observations. The source evaluation plan and manifests are included here; full session and hand traces remain in the local MGX-RL-Artifacts directory and their SHA-256 values are in `strength-audit.json`.

The preregistered minimum improvement was 0.05 BB/hand over published Beginner in overall, cash and MTT. The unpaired, cell-stratified session bootstrap gave candidate-minus-Beginner +0.256 [95% 0.214, 0.298] overall, +0.157 [0.108, 0.209] cash and +0.354 [0.287, 0.420] MTT. All candidate opponent-profile absolute lower bounds were positive. No cell met the preregistered material-regression veto (difference upper 95% bound below -0.10 BB/hand). The 13 negative point-estimate cells, including 2/2-MTT pressure, are described in `weak-cell-diagnostics.json`; none has an upper 95% bound below zero. Their action and response counts are descriptive, not causal.

Cash uses a 25% interpolation between the trained Beginner and the 2,000-hand trained Standard weights; MTT uses 75%. In a two-seat MTT, the ONNX selects the published Beginner network using only the public tournament flag and table size. This is an explicit safety route for the condition that regressed in the preceding frozen candidate. No gradient training was performed after the 2,000-hand Standard checkpoint.

Isolated Chromium/WebKit preflight passed ten cases before the frozen evaluation. The unpatched product route later passed eight normal cash/MTT browser cases (24 hands and 590 model-used CPU decisions), two custom-practice-MTT UI cases and two injected eight-second timeout cases with legal fallback. `product-preflight-audit.json` records artifact hashes. These local browser runs used API stubs; production delivery and strength against humans or ICM-sensitive tournament play require separate verification. The model is adopted as the evaluated scripted-opponent Standard policy, not as a claim of universal superiority in every cell.
