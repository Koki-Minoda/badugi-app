# モバイル対局画面の再設計 — 2026-09-20

利用者から「数字が入力できない」「レイアウト崩れ」「種目ごとの表示の不統一」の指摘を受け、スマホ対局画面の構造を作り直した。以前の合格判定は実際の使いやすさを十分に裏付けていなかった。特に金額欄は、文字サイズ・クリック成功だけでは指入力の支障を検出できていなかった。旧記録は当時の検査記録として残し、今回の判断は本書を優先する。

## 変更した内容

| 対象 | 新しい仕様 |
| --- | --- |
| 通常対局35種目 | 同じ席配置、カード、色、手番表示、操作領域へ統一。絶対位置で席を重ねる構造を廃止 |
| 縦・横 | 縦はテーブルの下、横は右側に操作をまとめる。全35種目で縦対局を可能にした |
| 手札と公開情報 | 自分のカードを大きく表示。縦向きで相手のカードが6枚以上なら2段にして「10」の欠けを防止。伏せ札・公開札、交換カードの選択を維持 |
| 金額入力 | 専用の数字キーを開く。最初の数字で既定額を置換。削除・全消去・候補額・キャンセル・確定を用意 |
| 入力範囲 | 範囲外は入力を勝手に補正せず、理由を表示して確定を無効化。数字は今回追加するチップ数 |
| タップ | 金額キー・確定・通常の操作は高さ44px以上。OSキーボードを開かず、短い横画面でも操作が隠れない |
| 選択から対局への移動 | Safariが前画面のスクロール位置を引き継いで上へずれる問題を修正 |
| Chinese / OFC | 共通カードと色・ボタン規則を適用。配置型の操作は維持。横画面のOFC下部を2列に整理 |

- 追加のスクロール位置修正後、NLH・Badeucey TD・Studを再プレイ。開始直後も全席が画面内。NLHボード5枚、Stud手札7枚の状態も撮影・測定した。

## 検査の範囲と残る確認

ブラウザによる端末再現では35種目の縦横に加え、小さい画面320×568・667×265で代表5種目を確認。4画面サイズで金額の置換・キャンセル・確定を検査する。カードが増える途中の局面も検査し、開始画面だけの判定を避ける。

新画面の縦向き実機は端末の回転待ち。ホーム画面への追加・PWA再起動はこの変更の完了条件には含めず、全体台帳では未確認を維持する。1ハンドの確認は全役・サイドポット・長時間対局を網羅した意味ではない。OFCはclassic 13枚でありPineappleではない。ソルバーやゲームエンジンの変更は行っていない。
