# 画面の使いやすさQA — 再設計後

**追加修正:** 2−7とNLHの種目間比較で残った差を修正。[最新の比較検査](FAMILY-CONSISTENCY.md)を参照。実機縦向きはNLH・2−7 TD・2−7 SD・Studの4種目を確認済み。

利用者から金額入力不能と種目間の表示崩れの指摘があり、以前のQAでは実用性を十分に確認できていなかった。今回の[デザイン再検査](DESIGN-REVIEW.md)を最新の判定とする。

| 視点 | 変更と確認 | 残る限界 |
| --- | --- | --- |
| 種目を変えても同じ操作位置か | 35種目で共通の席・手番・操作領域。実機横35種目を各1ハンド | 初見利用者の理解度調査は未実施 |
| 金額を指で指定できるか | 数字キーを独立表示。利用者の実タッチで88→削除→80→確定を観測 | 「押しやすい」という主観的回答は未取得 |
| キーボードで画面が狭くならないか | OSキーボードを使わない方式。実機高さ283pxを維持 | ログイン等の文字入力は別の画面 |
| カードが増えても崩れないか | 対局の途中でもカードと席の範囲を測定。Stud7枚、ボード5枚を撮影 | 全配牌の見た目を網羅したものではない |
| 次の操作を一目で見つけられるか | 自分の番を強調、交換枚数をボタンに表示、結果の次ハンドを固定 | 詳細ルールは「ルール」から参照 |
| 小さい画面でも入力できるか | 320×568・667×265で代表5種目。数字キーは計4サイズで検査 | 物理端末は接続中のiPhone1台 |
| 大会でも操作できるか | 3形式×縦横6件で配置、対局、再開を確認 | 終了画面検査には明示的な優勝フィクスチャを使用 |
| Chinese/OFCとの統一感 | 共通カード・色・操作サイズを適用。実機横各3ハンド | 配置型ではテーブル詳細のスクロールが必要 |

実機の自動対局はDOMから画面のボタンを操作しており、全操作を人間の指で行ったという意味ではない。実タッチ確認は金額の入力・修正・確定のみ。新画面の実機縦向きは、追加修正後にNLH・2−7 TD・2−7 SD・Studの4種目を確認した。

検査数と種目別結果は[検査記録](redesign-evidence.json)、未確認項目を含む一覧は[全体台帳](STATUS.md)。
