# プレイヤーが迷わず操作できるかのQA

今回の判断は、自動操作の成功だけでなく保存した画面の目視と、操作位置・文字サイズ・遮蔽の測定に基づく。初見ユーザーによる観察調査や物理タッチの測定は未実施。

| 視点 | 問題と対応 | 確認 |
| --- | --- | --- |
| 今は自分の番か | 「あなたの番」と必要な操作、待機時は相手名を表示。スマホの細かな補助情報を減らした | Badugi/Stud/NLH/PLO/Dramaha、5画面構成で手番案内を確認 |
| 何枚交換するか | ボタンに選択枚数、0枚なら「交換しない」。交換前の誤ったPATを除去 | 実操作で選択→交換、null/0/5枚をユニット確認 |
| カードを読めるか | 小さいカードの重複した数字・スートを1組に整理 | Android/iPhone相当の横画面を目視。重なりが解消 |
| 結果がすぐ分かるか | ポット総額の0表示を修正し、獲得者の名前を結果上部に固定 | 全23種目で金額整合。代表種目の短い横画面で獲得者が画面内 |
| 次に何を押すか | 結果の詳細だけをスクロールし、履歴・精算・次ハンドを固定 | ボタンが画面内、高さ44px以上、中心を他要素が覆わないこと |
| 金額を入力できるか | ベット入力を16pxにし、補助ボタンの大きさを拡大 | 計算済み文字サイズ16px以上。実機のキーボード展開は未 |
| 開始前に流れを理解できるか | Dealer’s Choiceにプレイ順と繰返しの説明。新大会には人数・交代間隔・順位点を表示 | 選択→開始→実対局→戻る、3形式の中断再開 |
| OFCの置き方が分かるか | 3/5/5枚の行、選択カード、取消、配置確定を表示。未配置カードと確定を画面下部に固定 | 手動配置・取消・確定・保存後再開、5画面構成各10ハンド |
| 次にどの種目へ変わるか | 新大会の卓別・決勝順から案内を算出 | 卓ごとの次種目と決勝開始位置をユニットで確認 |
| 縦横で見切れないか | 縦非対応種目は横向き案内、対応種目は縦で対局可能 | 公開23種目の縦横46件＋検証中12種目の縦12件 |

端末を模したブラウザでの確認は合格。ただし、画面の分かりやすさの改善余地が完全になくなったという判定ではない。既存の英語ラベルは一部残っており、OFCの相手の配置や詳しい結果は縦画面でスクロールが必要。実機の安全領域、指で狙いやすいか、キーボードを開いたままの操作は接続復旧後に確認する。

証拠は[検査集計](completion-evidence.json)。画像はローカルの `artifacts/usability-last/` 内の各画面構成の `playing.png` / `result.png`、OFCは `ofc-first-result.png` など。検査用アカウント名を含む可能性があるため画像の外部公開はしていない。
